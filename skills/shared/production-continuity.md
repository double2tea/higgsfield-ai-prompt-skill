来源包含 74 个非空图片提示词节点、432 个非空视频提示词节点，分别有 64、319 条

对白、完整提示词或素材地址。

## 0. 资产先达到当前镜头所需的可读条件

参考资产的职责声明需要与图中事实一致。首帧已经带错脸、过度光滑的皮肤或错误隔断，
一句“只参考构图”不能证明这些错误会被忽略。先查看当前输入，在本次授权范围内修正
会影响目标镜头的缺陷；不因此重新制作全部资产或强制再生成一批。

| 资产 | 按镜头需要检查的内容 |
|---|---|
| 人物 | 可辨识外形、批准的服饰与身体比例；近景需要时才补可读面部与皮肤纹理 |
| 空间／载具 | 布局、尺度、座位、门窗、隔断、可达路径与光源；多视图只用于需要核对的几何 |
| 道具 | 功能部件、接触面、显示内容、正反面、厚度及材质；文字与数值是否真正可读 |

**选角与身份锁定分开。**探索期可按授权改变五官或气质；身份获批后的换装、年龄或
材质派生保留未请求改变的特征。不能把选角时“允许改脸”的指令带进后续一致性稿。

**保持式改图声明当前变化。**从选定基件继承批准的身份、结构、影调等，只改变本次
要求的属性；换机位时不能同时声称构图完全不变。材质修正说清适用部位与程度，例如
降低局部油亮高光并保留柔和阴影与功能边缘；不把所有皮肤都磨粗或所有产品
都做旧。批准的光线、材质、幻想与美妆光泽可属于核心目标，不一律降为次要偏好。

沿用现有设定图的背景与 face-lock 方法，不把来源项目的纯白底覆盖成本库的灰底规则。
下游只需一张脸或一个角度时，按需要取出可读视图，并核对身份；板式、文字标注和多视
排列仍须限定继承范围。裁剪本身不证明身份正确或比例一致。

已验收片段的静帧可作为该场或相邻镜头的构图／影调参考；记录来源与采用范围，不凭
“截图”“高清”名称认定它获批，也不把有漂移的尾帧升级成全项目身份母版。项目原始
身份基准继续保留；静帧不能替代动态交接。

来源中的特定模型组合、2K／4K、出图数量、胶片型号与反复引用次数只描述该项目。
不推断高分辨率、多模型或更多批次会自动提升真实感；实际参数、预算和提交仍归执行器。

## 1. 素材职责要落到真实绑定

继续使用已有的“采用什么／排除什么”与保真等级，不靠文件名或上传顺序猜角色。
混排绑定计入图片、视频和音频的实际有序输入，不能只数图片列表。修订后检查标签在
全文每次出现时是否仍指向相同职责；表头正确而后文用声音标签描述外貌，仍是绑定冲突。

- **结构素材**只提供布局、物体结构或玻璃等光学关系时，明确排除素材中的人物、
  板式或占位背景。若素材有绿幕而成片没有，排除的是绿色背景，不是玻璃本身。
  绿幕不是通用默认流程。
- **声音素材**只提供声线时，不继承原句、配乐或全部场景声；人物外貌由对应图像
  决定。需要原句或原始声景时，则保留用户选择的继承范围。
- **同一物体的多视图**先说明物体数量，再说明每张图代表的视角或表面。两张正反面
  素材不等于两个道具。

LibTV 来源中，195 条不重复视频提示词使用 `{{Mixed N}}`，也有 `{{Image N}}` 和
`{{SegmentRange:…}}`。这些是该平台的绑定语法，不据此评价哪种写法效果更好。
保留已批准文本、实际素材顺序及执行器生成的标签；不要改成 Higgsfield 的 `@Image 1`，
也不要把 Higgsfield 的 house convention 当作其他平台的标签禁令。迁移时先让目标
执行器核对素材映射，未核对前不宣称跨平台可直接执行。

## 2. 交接记录保存状态，执行提示词只写必要变化

在已有分镜或项目记录中，只记该片段真正可能出错的状态，不新建重复的制作日志：

| 检查对象 | 需要交接时记录什么 |
|---|---|
| 人物 | 位置、朝向、视线目标、动作进行到哪一步 |
| 道具 | 数量、持有人、左右手、正反面、是否收起、显示内容 |
| 空间 | 真实距离、车辆运动、门窗状态、前后排或左右位置 |
| 摄影 | 机位、运动阶段、焦点主体、遮挡物及方向 |
| 声音 | 台词是否说完、可见／画外声源、持续环境声 |
| 叙事 | 已完成的事件、必须留给下一片段的事件 |

已接受的源视频携带可见和动态状态，执行提示词主要写下一步变化；这张表是规划与
核对工具，不要求全文重复进提示词。只用静帧接续时，补足它无法携带的运动方向、
摄影运动阶段与声音进度，沿用 Source-carries-state rule。

连续接续要对上源片尾态；明确的时间跳切可重新建立空间。不要把上一段已握住的
道具重新放回桌上取一次，也不要在第一段提前完成后段才需要发生的离场或告别。

约束分清全项目、单场、动作阶段和本次编辑范围。身份固定不等于禁止授权年龄变化；
一场的座位锁定不属于每个版本。替代 take 是候选，不自动接成追加剧情；未确定哪个
版本获批时保留未决，不能凭最长稿或最新节点名拼出一套相互冲突的“常量”。

## 3. 世界位置、画面方向与光源分别描述

- 区分人物／车辆的真实左右与画面左右。前后排、驾驶位、门窗位置要属于同一空间；
  正反打再分别写画面位置和视线方向，避免换机位后人物互换。
- 长焦近景不改变人物的真实距离。需要远距离正反打时，背景、视线与声音距离仍要
  对得上；不要因为切近景就让两人变成近距离面对面。
- 分清角色能感知的刺激与观众通过长焦看见的细节。远处的细小眼神可以给观众读，
  另一角色的反应仍需由其能感知的停步、身体朝向、声音或剧情线索触发。
- 窗户或灯的位置固定在场景里，换机位后脸上受光侧可能变化。不要要求每个角度都
  维持同一画面侧的高光，导致世界光源跟着摄影机移动。
- 遮挡来自真实物体和开口：窗框、车体、前景行人可以间歇挡住远处主体；不能为了
  看清主体让整面墙或车体透明。情绪需要可读时，把焦点放在实际承担表演的主体上。
- 接触与反射按当前几何成立：手不能穿过锁定隔断，摄影机不能穿过实体；镜中可见谁
  取决于镜面、主体与机位。失焦主体用可见的轮廓或重心承载必要反应，不要求无法读出
  的眼神；批准的主观失焦风格仍可保留。

空间复杂或已有轴线错误时才补调度图；简单镜头用明确的位置关系即可。

## 4. 双面道具是一件有厚度的物体

先绑定“同一件物体的 A 面／B 面”，再描述有方向的翻转过程：A 面 → 边缘 → B 面。
厚度、折痕、边缘与持握点属于同一物体；避免两面融成一面、变成两件物体，或文字
穿透到背面。示例仅展示关系，素材编号由执行器绑定：

```text
素材 A 和素材 B 是同一张卡片的正面与背面，全程只有一张卡片。
人物捏住右下角向外翻转，卡片先侧向露出边缘，再露出背面；持握点保持连续。
```

仅在该风险实际存在时补这些约束，不机械追加长串否定词。风吹、惯性或接触动作
应写清原因、受力与结果，但文字约束不保证模型能精确完成物理过程。

## 5. 变化需要过程和落幅时间

继续采用已有的阶段、主事件与终态结构，不复制来源项目的固定秒数或镜头数量。

- 时长预算包括动作发生、可见反应和结果停留；需要“离场之后的余韵”时，人物离开
  不是自动结束点。先明确终态要让观众读懂什么，再分配过程和停留时间。
- **选择性时间压缩**要指出谁在加速变化、谁保持正常速度。比如只让某个物体风化，
  周围车辆、行人和光照仍按场景要求运动；保持该物体的连续身份，不偷换成另一件。
  可见渐变与完全遮挡期间更换状态是两种制作方法；按批准意图选择并分别核对，不能
  叠成同一时刻既持续可见变化又只在遮挡时变化的要求，也不宣称哪种一定更稳。
- 关注 → 反应 → 终态可帮助描述一段具体表演；静止、无反应或省略过程也可以是用户
  的选择，不把这套关系强制套进所有镜头。
- 背景人物有各自的轨迹，不因主角反应同时停下或集体回头。持续环境声不随一次
  近景无故静音。需要现场声学时保留真实距离与声源线索；批准的收音／混音视角不必
  机械随摄影机距离衰减。设备播放旧录音不自动要求画中人物对口型。

来源中的无配乐、硬切、长镜头和特定年代是作品选择，不是本 skill 的新默认值。

## 6. 草稿、正片与超分是不同的生成操作

观察到的 78 对关联记录采用 480p 草稿设置和 1080p 正片设置。这只能证明该项目保存
了这条工作关系，不能证明所有草稿获批、正片完全一致，或默认应该先做草稿。

用户选中草稿后，若该平台支持从草稿生成正片，保留选中版本的素材映射、参数和源
任务关联；不要另建无关联任务冒充同一草稿的正片。当前节点中的可编辑文本不一定
等于历史提交文本，提交收据和选中版本才是核对依据。

正片生成、重新生成和超分按用户要求与执行器能力区分：只要超分时，不强制再进行
一次创作生成。费用与提交授权继续由选定执行器处理。

**编排长度不等于模型单次上限。** 来源保存了 60／80 秒等长视频编排字段；不能把
它们当作模型原生时长。核对当前执行器的单段能力、片段关系与实际媒体时长。

**请求配置不等于交付规格。** 一份抽查记录保存了 1080p 设置，持久化媒体元数据为
2206×946，审阅投影却报告 816×350。这是不同字段的尺寸口径冲突；未核对原始媒体，
不能把投影尺寸断言为交付母版尺寸。标题、设置和“正片”字样不能替代产物核对。
按交付要求检查原始媒体的宽高、时长与音轨；提示词里的 `8K`、帧率或宽银幕风格也
不等于参数已经生效。
未说明含义的 schema 值不解释成无限输入。

## 7. 局部修复只解决明确缺陷

沿用编辑母版、修改范围与时间线继承规则。只改一个显示数字、道具表面或指定区间
时，绑定源视频、实际范围和必要的目标参考，不重写整段故事或人物表演。

由当前执行器获取 `{{SegmentRange:…}}` 等选择标签；不复制其他任务的 ID，不虚构
范围。交付时核对范围前后接缝、遮挡关系与声音，以及用户要求保留的区域是否真的
保留。提示词中的“其他全部不变”是目标，不是产物已达到像素一致的证据。

## 8. 修订稿检查本次改动留下的冲突

检查围绕新写或已授权修订的内容，不要求每次执行旧稿都重新做创作审查。发现已批准
文本存在矛盾时先指出具体冲突；没有修订授权，不静默清洗、截短或翻译执行提示词。

- **绑定与状态：**全文的标签类型、正反面编号、座位、左右手、道具数量与当前输入一致；
  不能只查第一处参考声明。
- **对白与反应：**对白改后，同步检查原词上的停顿、打断、反应和说话人；旧台词已删，
  旧词上的表演锚点也需处理。不同覆盖镜头的同一句话不自动变成连续重说。
- **执行稿与讨论稿：**新稿明确选择方案，移除不属于执行内容的聊天开场／结尾；分析、
  修改理由与可复制稿分开。未批准的候选不靠合并全部备选来“解决”。
- **正向与否定项：**例如一镜到底的目标不能又出现在否定列表中；年代、动作速度、
  开场状态和落幅要求不互相取消。批准的虚构例外不按现实年代知识擅自删除。
- **三种时间：**区分源片内时间、剪辑偏移与整片时间。文字时长、节点设置和实际媒体
  不一致时核对实际请求；顶层字段与 `settings` 冲突时，不猜哪一项生效。
- **关联与命名空间：**“继续”或一条连线不证明实际源片已绑定；内部剪辑 ID、旧任务 ID
  与画布节点 ID 可能不同，先核对映射，再判断是否缺素材。复制的旧任务不证明新生成
  或新扣费，完成状态不证明创作验收。

这些检查用于定位可说明的矛盾，不作为付费重试、固定批次、固定微动作数量或统一
优先级符号的触发器。节点统计描述使用情况，不能计算未核实的失败率、通过率或成本。
